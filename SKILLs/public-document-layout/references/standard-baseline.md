# 标准基线

本 Skill 的正式公文模式以 GB/T 9704-2012《党政机关公文格式》为主要依据；电子显现可结合 GB/T 33476.2-2016。

已核验的国家标准信息：
- GB/T 9704-2012：国家标准，推荐性，当前状态为“现行”；发布 2012-06-29，实施 2012-07-01。该标准在国家标准公共服务平台显示上次复审结论为继续有效。
- 相关电子公文标准包括 GB/T 33476.1-2016、GB/T 33476.2-2016、GB/T 33476.3-2016。

本 Skill 不把“内部材料排版”“视觉优化样式”宣称为国家标准格式。实际发文前应以本单位秘书、文印或电子公文系统的最新要求为准。

常用页面基线：
- A4：210mm × 297mm
- 正式公文常用版面：上 37mm、下 35mm、左 28mm、右 26mm
- 标题：二号小标宋体类字体
- 正文：三号仿宋类字体
- 一级标题：黑体
- 二级标题：楷体
- 页码：四号宋体类字体

实现时优先使用 OOXML 字符相对缩进、页码域和显式字体设置，减少 Word 默认样式造成的漂移。
