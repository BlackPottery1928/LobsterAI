# 版式方案

## 标准严谨
黑白、强规范、低装饰，正式发文默认方案。

## 清正文务
适合工作汇报、阶段总结、情况说明；减少密集层级造成的阅读压力。

## 稳重政务
适合正式汇报；标题与重点段落区分更明显，但不使用花哨装饰。

## 会议纪要
信息密度高，强化会议基本信息和议定事项。

## 制度条款
适合制度、办法、细则、方案；强调多层级编号和表格。

## 调研报告
适合调研材料；可用“基本情况—问题—原因—建议”信息架构。

## 讲话材料
适合讲话稿和发言稿；段落留白更舒适。

## 极简黑白
适合内部流转、打印量大的材料。

使用原则：
- `official/red/order/letterhead/minutes` 不得擅自加入非标准装饰。
- `briefing/policy/meeting/minimal` 才允许在范围内进行视觉优化。
