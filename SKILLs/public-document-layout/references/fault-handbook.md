# 故障手册

### Word/WPS 打开提示修复
优先检查 DOCX ZIP 结构、关系文件和 settings.xml，而不是重新生成全部内容。

### 字体显示不一致
不要只依赖 Word 样式。对关键文字执行 run 级字体设置，并为东亚文字与西文分别设定字体属性。

### 版面靠空格对齐
不要用大量空格模拟左右对齐。使用制表位、段落缩进、表格或版式对象。

### 首行缩进异常
正式正文优先使用字符相对缩进，避免固定厘米值在字号变化后失真。

### 表格文字发生缩进
表格段落单独清零首行缩进，不能沿用正文规则。

### 图片位置改变
排版时优先跳过带 drawing/pict 对象的段落；不要通过重建段落强制重排。

### 页码显示为无数字
使用 PAGE 域，并在 settings.xml 中启用 updateFields；奇偶页需要独立页脚。

### 版记页出现页码
创建新 section 后解除 footer 与上一节的链接，并清空 default/even/first 页脚。
